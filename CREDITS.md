# Credits

## Sound

Every sound effect (putt, wall clink, splash, freeze crackle, gunshot, siren, cup rattle and the rest) is synthesised at runtime with the WebAudio API in `client/src/fx/sound.ts` and `client/src/fx/siren.ts`. No audio files are bundled, so there are no third-party sound assets to license.

## Art

All visuals are drawn in code (Phaser shapes, emoji text). No image assets are bundled.

If audio or image files are added later they must be CC0 (for example from kenney.nl or opengameart.org) and listed here with their source URL.
